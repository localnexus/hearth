# 3.5 Session continuity (Tier 1) — resume a conversation across a restart

*What this covers: the opt-in memory that survives a crash/reboot/LM-Studio restart — where the transcript lives, the ephemeral-by-default rule, and the resume/hold/discard CLI.* · Runbook index: [`README.md`](README.md)

Opt-in memory that survives an earbud-battery death / crash / reboot / LM-Studio restart.

- **Where it lives / what it is:** `sessions/<id>.json` — a **full plaintext
  transcript** of one conversation (the LLM message list; the persona prompt is NOT stored).
  Local-only, **gitignored**, dir `0700` / files `0600`. Rewritten after every turn (atomic).
- **Ephemeral by default:** a graceful `./stop.sh` **truly deletes** the file. An unclean death
  (`kill -9`, crash, outage) leaves it as a **recoverable orphan**.
- **Resume:** `./start.sh --resume` (picks if >1, metadata only) · `./start.sh --resume <file|name>`.
  The bot stays silent until spoken to, then answers with the reloaded memory (no auto-greeting).
- **Bare `./start.sh` → chooser (interactive terminal):** a metadata-only menu — `0. new session`
  (discard ephemeral orphans, keep held) + every resumable session by name/timestamp (held ones too,
  so named work-topics are pickable); Enter/Ctrl-C cancels. **Non-interactive** (launchd / web, stdin
  not a TTY) keeps the hard **guard** (`exit 2` on orphans → re-run with `--resume` / `--new`).
- **Keep one:** `./stop.sh --hold [name]` promotes the session to the **held** class (sticky,
  purge-exempt, optionally named for `--resume <name>`). Remove held: `./stop.sh --discard-held <name>`
(targeted) — a bare/`--all` wipe of **all** held sessions is irreversible and requires typing **`HEARTH`** to confirm (refused non-interactively).

Never expose `sessions/` over the web `/` or sync it. See [debugging/session-continuity-faults.md](../debugging/session-continuity-faults.md).
