# GLOSSARY 0–9 — numeric conventions

Number/symbol-keyed conventions cited across the docs.
Index + how-it's-organized: [`README.md`](README.md). Alphabetical terms: [`A-M.md`](A-M.md) ·
[`N-Z.md`](N-Z.md).

- **`:8080`** — the local OpenAI-compatible LLM endpoint the bot talks to by default (`llama-server`).
- **`:1234`** — the same endpoint when the LLM is served by **LM Studio** instead (the supported alternative).
- **`:65000`** — the local control-panel port (loopback-only by default).
- **16 kHz** — the fixed microphone-side sample rate (Whisper expects it); do not change the input rate.
- **24 kHz** — Chatterbox-Turbo's native output sample rate.
