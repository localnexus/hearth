# GLOSSARY — terms, acronyms & shorthand

**What this is.** The plain-language decoder for this project's acronyms and shorthand — so someone
**new to this work** can read the other docs without prior context.

## How it's organized

Terms are distributed **alphabetically** across three shard files; numeric conventions get their own file:

| File | Holds |
|---|---|
| [`0-9.md`](0-9.md) | **Numeric conventions** cited across the docs. |
| [`A-M.md`](A-M.md) | Terms, acronyms & shorthand beginning **A through M**. |
| [`N-Z.md`](N-Z.md) | Terms, acronyms & shorthand beginning **N through Z** (incl. symbol-prefixed like `--new`). |

Each entry is a one-liner: **term** — expansion (for acronyms) — what it means in one line.
