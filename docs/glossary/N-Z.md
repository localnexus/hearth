# GLOSSARY N–Z — terms, acronyms & shorthand

Alphabetical, N through Z (symbol-prefixed terms filed by their word, e.g. `--new` under N).
Index + how-it's-organized: [`README.md`](README.md). A–M: [`A-M.md`](A-M.md). Numeric / ID schemes:
[`0-9.md`](0-9.md).

- **`--new` guard** — the safeguard causing a bare non-interactive `./start.sh` to exit 2 when a recall-only leftover exists, preventing silent loss of its one recovery chance. `--new` starts fresh, sweeping only recall-only leftovers (saved and held sessions are never touched).
- **NLTK** — Natural Language Toolkit. Python NLP lib; pipecat's sentence splitter (`match_endofsentence`).
- **orphan(ed) session** — historically, any unheld file left by an unclean exit; since saved-by-default it means a **recall-only leftover** (a crashed `--memory recall-only` sitting's file — every other crash survivor is simply a saved session). Recoverable via `./start.sh --resume`; triggers the *`--new` guard* on the next bare non-interactive launch.
- **overrides.toml** (`config/overrides.toml`) — the **live-config** override file: `[llm]` / `[tts]` / `[voice]` sections holding the hot-reloadable knobs read each turn by `config_reload`. Overlays the baselines (`model.toml`, `config/tts/<engine>/tts.toml`); empty sections = pure defaults.
- **paralinguistic cues / voiced-breath cues** — the nine whitelisted cue tags the LLM may emit — `[laugh] [chuckle] [sigh] [gasp] [groan] [sniff] [cough] [shush] [clear throat]` — which **Chatterbox-Turbo consumes as real breath/sound events, never spoken aloud**. Governed by a placement law (set off with punctuation, keep the turn short, never buried mid-phrase) + a restraint-first framing in the model-layer prompt. A cue also *conditions the delivery of the surrounding words* (the affective channel), not just the gesture event. Source: `config/models/<model>/system-prompt-template.md`.
- **paralinguistic tag repair / normalization** (`paralinguistics.py`, `normalize()` / `normalize_with_report()`) — the deterministic LLM→TTS text pass that hardens the *voiced-breath cues* before synthesis. Hooked in `mlx_tts_service.run_tts` (`:357`, after the whitespace/ellipsis normalize). Three behaviours: (1) **repair** — a *bare* cue root wrapped in `*…*` / `(…)` / `[…]` / `{…}` is rewritten to the canonical `[tag]`, tolerant of case/padding/morphology (`*SIGHS*`, `{sighing}` → `[sigh]`), for the nine cues (aliases: `moan`*/`murmur`* → `[groan]`; `sniffle` → `[sniff]`); (2) **curated phrase** — a narrow whitelist crossing the +1-word line (`[soft sigh]` → `[sigh]`), NOT a general modifier rule; (3) **strip** (the one destructive op) — a **CATCH-ALL**: *every* square-bracketed token that isn't one of the nine canonical cues is removed, applied **after** repair — post-repair, a surviving `[bracketed]` token is by definition not a cue, and Chatterbox would speak it aloud (`[softly]`, `[gentle smile]`, `[warmly]`). Still **square-brackets ONLY**, so `*gentle smile*` / `(gentle pause)` prose survives and the `*asterisk*` prose leak stays uncovered by design. Each strip is **reported** (`normalize_with_report()` → `(clean_text, strips)`) and classified `known` (the settled `smile`/`pause` families) vs **UNKNOWN** (novel) — the caller logs it (see *paralinguistic strip log*). The module itself stays **PURE** (stdlib `re` only, no I/O, no logger): the report is returned, the side effect is the caller's. Idempotent, no-op on canonical tags, zero latency, never touches prose/placement/non-square enclosures (`test_paralinguistics.py`, 159/159).
- **paralinguistic strip log** (`logs/paralinguistic-strips.jsonl`) — the append-only JSONL record of every bracketed token the *tag repair* pass stripped, written by `mlx_tts_service._log_strips` (one object per strip: `ts` · `token` · `known` · `context_id`). **UNKNOWN strips are the point** — a tag the model reached for but the engine has no channel for (e.g. `[softly]`) surfaces here without anyone having to predict it in advance; this is the intended way to discover unsupported tags, replacing discovery by ear. `known` families are already-settled and stay out of the logger so they don't bury new signal. Reviewed *after* a conversation, not watched during one. Best-effort — a log fault can never break the voice loop. Lives in `logs/`; gitignored (verbatim model output).
- **persona (two-layer prompt / `{{persona}}` slot)** — the CHARACTER layer of the system prompt: `persona.md`'s `## IDENTITY` (stable *who*) + `## SOUL` (tunable *how*) sections, composed into the `{{persona}}` slot of the MODEL layer (`config/models/<model>/system-prompt-template.md`, which owns the output-shaping hard rules). The rendered `system_instruction` is byte-equivalent to the old literal.
- **per-turn voice (pause/resume valve)** — `POST /memory/per-turn-voice {"on": bool}` on the **:65000** control panel: a runtime-only pause/resume of the live memory seam's `per_turn_voice` gate (the per-turn targeted voice-memory recall). A pure in-memory poke — `memory.toml` is never touched — so it takes effect at the next turn and reverts to the file's own setting on the next bot start. See `docs/memory.md`.
- **phantom-phrase** — words Whisper hallucinates on near-silence (e.g. "thank you"); filtered by a guard list in `run_stt` before they fake a turn.
- **PTT** — Push-To-Talk. Hold to open the mic (control panel).
- **rebuild / `--clean`** — `python -m hearth.memory rebuild`: replay every canonical record, oldest first, into the configured backend (a newly adopted backend inherits the whole history; A/Bs stay fair). `--clean --yes` WIPES the backend index first, then replays the survivors — the recovery path after forgetting pre-keyed content, and the one-time migration to the **session-keyed store** (each session = one bank document; a resumed session's re-store updates instead of duplicating).
- **reliable_context** (`model.toml`) — the **measured usable context ceiling** (`128000` today) the control panel's `Tokens` gauge counts against, instead of the advertised `loaded_context_length` (262,144). A **PROVISIONAL** cost/prudence cap, NOT a measured recall cliff (a needle sweep found none to ~207k). Rides `/engine` as `engine.reliable`; absent → the panel falls back to the advertised window. Drives the **context-budget gauge / zones** (see `A-M.md`).
- **resume** — `./start.sh --resume [file|name]`: reload a prior session's message history into a fresh pipeline run. Bare `--resume` with >1 candidate shows a **metadata-only picker** (timestamp · #turns · model · voice — conversation content is never displayed).
- **roster (wizard)** — the facade's `/admin/roster` (supervisor on): the character-onboarding + editing surface. Mechanizes directory scaffolding, reference-clip conditioning, `voice.toml` + `VOICE-SOURCE.md` generation, and a loader-verification probe (the exact startup path); onboarding is **create-only** (an existing character answers 409). The same door also holds a persona editor for existing characters and the **Branch card** — the panel form for the *fork (memory verb)* (`A-M.md`), `POST /admin/roster/fork`. Ends by handing off to the *launch page*; grows no restart button of its own.
- **RSS** — Resident Set Size. Process RAM in use; watched in the soak test for leaks.
- **RTF** — Real-Time Factor. Gen-time ÷ audio-duration; **< 1.0 = gapless** (faster than playback). ~0.34 ≈ 3× realtime.
- **S3Gen / T3** — Chatterbox-Turbo internal sub-models (speaker + speech-token conditioning); cited to explain why cloning is textless / robust to transcription error. (S3Gen decoder conditions on the first ~10 s of a clip; the speaker encoder on the first ~15 s.)
- **settings (forms)** — the facade's `/admin/settings/ui` (supervisor on): a generated, schema-driven form for every file-configurable knob (no separate front-end build — plain JS walking the served settings registry as JSON Schema), so a knob can't exist without appearing. Reads use the same strict verdict as `python -m hearth.config.check`; writes are one scalar key at a time via comment-preserving line surgery, refused rather than guessing if the edit can't reproduce the file exactly. A knob that's panel-managed or secret-marked is refused with a pointer to the right place instead (the **:65000** panel, or the desk).
- **session snapshot** — the atomic per-turn write of the LLM message list to the companion's `sessions/<id>.json`, via `<id>.json.tmp` → `os.replace`. The only durable conversational state that needs preserving (persona prompt is injected per-request from settings and is never stored in the file).
- **Silero** — the VAD model (via onnxruntime; no torch needed).
- **Smart Turn** (v3.x) — pipecat's semantic end-of-turn model, loaded alongside VAD; can end or hold a turn beyond raw silence.
- **STT** — Speech-to-Text. Transcription (MLX-Whisper).
- **TCC** — Transparency, Consent & Control. macOS privacy framework; grants mic **per-app** (the terminal), not per-process → the silent-STT failure if unset.
- **"the box" / "sensitive text stays local"** — house phrasing for the local-only privacy posture: nothing leaves this machine.
- **TPS** — Tokens Per Second. LLM generation rate (see spec).
- **TTFA** — Time To First Audio. Latency from synth start to the first audio chunk at the speaker.
- **TTFT** — Time To First Token. Latency to the LLM's first token (see spec).
- **TTS** — Text-to-Speech. Voice synthesis (Chatterbox-Turbo).
- **VAD** — Voice Activity Detection. Silero classifier; detects speech start/stop → turn segmentation **+** barge-in.
- **voice descriptor / voice bundle / `voice.toml`** — a **self-contained** dir `characters/<char>/voices/<name>/` holding `voice.toml` (min keys `tag` + `ref_wav`; optional `license` / `source` provenance + engine facts `model_repo` / `sample_rate` / `streaming_interval`) and the **vendored** `sample.wav` clone-reference clip. Discovered by path (no registration/index step); selected via `voice =` in `active.toml`; its `ref_wav` is HIDEABLE-hot-swappable via `overrides.toml`. Recipe + template: [bring-your-own-voice.md](../bring-your-own-voice.md).
- **WER** — Word Error Rate. STT accuracy metric.
- **WSOLA** — Waveform Similarity Overlap-Add. Pitch-preserving time-stretch algorithm (for a pace-trim option).
