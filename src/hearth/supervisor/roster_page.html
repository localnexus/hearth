Launch page · Memory records · Settings · Control panel

New character

Creates characters/<name>/ — persona, voice bundle, provenance record — and verifies it with the same loaders startup uses. Existing characters are never touched. Audition stays yours: your ear decides what goes live.

Edit a persona

Rewrites persona.md (or a variant) for an existing character. Writes land in your data root — a shipped persona is copied-on-write, never touched — with one .prev backup kept. Composition happens at bot start / live switch, never mid-sitting.

Add a voice

A new voice bundle for an existing character — create-only per tag, written to your data root (works for shipped characters too). The new tag shows in the switch pickers immediately; audition stays yours: your ear decides.

Branch a character

Forks the memory track at a juncture: a new character (persona as it stands today, voices, theme) whose records hold the shared history up to the cut — both lines diverge freely from there, and recall never crosses tracks. Records after the juncture, and the intent slot, stay with the source. Create-only; preview writes nothing.
