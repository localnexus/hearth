Three steps, then the companion is talking. Nothing here changes a file you did not ask it to, and every fact on this page is re-read from disk and from your server as you go.

The id is copied verbatim from the server's own listing into the selected model config — comments kept, the previous file beside it as .prev.

2Bring the companion up

The shipped example companion is selected; bring in your own later on the roster page. Press Start. The first start on a Mac also asks for the microphone — the prompt is addressed to the terminal app that runs the facade, so look there. Warming takes 10–20 s; the very first start also compiles kernels once.

There is no greeting — the companion waits for you. Within a few seconds of your pause you should hear a reply; talking over it cuts it off, which is barge-in working. This line reads the bot's own turn counter through the facade — no words cross.

That is the whole loop.

From here the launch page is the front door: start, stop, resume, switch companion. The control panel is the room you sit in while one is running. This page stops being offered once a session exists and the model id is set; it stays at /admin/first-run if you want it back.
